# Sanitized Public Tree Export Plan

## Goal

Prepare a deterministic export plan for a future official public repo copy while preserving strict public/private boundaries.

## Allowed in Export

- `README.md`
- `LICENSE`
- `package.json`
- `package-lock.json` (if present)
- `scripts/package-preview.mjs`
- `dist/` outputs generated for public artifact packaging
- `docs/` public-safe files listed in `PUBLIC_DOCS_INDEX.md` public section
- `public/` static assets currently in use for the shell UI
- Shell component sources and type/data files currently in `src/` that are explicitly static preview-safe
- `preview-artifacts/sparkbot-shell-preview-0.8.0-layer8/` artifact directory content
- Repository metadata needed for preview packaging and release audit trail

## Forbidden in Export

- `backend/`
- `src-tauri/`
- `.github/`
- `.agents/`
- server/runtime entrypoints
- private orchestration or scheduler code
- provider runtime/client dispatch code
- live connector transport/send/receive stacks
- memory persistence service code
- terminal/browser execution runtime
- secrets or credential stores
- private R&D branches or unreleased proprietary modules

## Public Docs Allowed

Allowed public docs remain:

- `docs/INSTALL.md`
- `docs/CAPABILITIES.md`
- `docs/ARCHITECTURE_OVERVIEW.md`
- `docs/SECURITY_AND_GUARDRAILS.md`
- `docs/LOCAL_AI_SETUP.md`
- `docs/ROUND_TABLE_OVERVIEW.md`
- `docs/TASK_GUARDIAN_OVERVIEW.md`
- `docs/CONNECTORS_OVERVIEW.md`
- `docs/ROBO_PREVIEW.md`
- `docs/BETA_LIMITATIONS.md`

## Package Metadata Allowed

- `package.json`
- artifact metadata generated by packaging script.

## Preview Artifact Policy

Public artifact remains static-safe:
- Include only shell app build output and allowlisted public docs.
- Exclude planning, extraction, staging, and internal readiness documents.
- Keep `LICENSE` + `README` + `package.json` + package metadata included.
- Keep `MIT` license framing intact.

## License Inclusion

MIT remains selected in this stage.
- Ensure `LICENSE` and `package.json` remain unchanged during export.
- Keep copyright ownership wording unchanged unless legal review requires wording adjustments.

## README Inclusion

- Include repository overview.
- Keep readiness state explicit: `GREEN_CANDIDATE`, `NOT_RELEASED`, `NO_TAG`, `NO_UPLOAD`, `NO_ANNOUNCEMENT`.
- Include option-gated release posture and repo-move pending status.
- Keep links branch-safe only after final cleanup.

## Source Boundary Rules

- No source file outside static shell surface area may be exported.
- No runtime assumptions or implementation imports.
- No API clients, runtime providers, or persistence adapters.
- No branch-specific workflow commands unless they are staging-only and explicitly safe.

## Denylist Terms

Block export if files/docs contain:
- `backend/`
- `src-tauri/`
- `connector send`
- `live provider`
- `model call`
- `persistence`
- `scheduler`
- `terminal`
- `browser execution`
- `robotics`
- `Arc`
- `Office`
- `LIMA`
- `.agents`
- `secrets`
- private domains/private IPs
- internal-only runbook URLs

## Verification Checklist

- Confirm all forbidden top-level folders are absent.
- Confirm no provider/model/runtime/connector/secret calls in export-scoped source.
- Confirm README and public docs have final-safe links.
- Confirm public artifact allowlist matches final allowed docs list.
- Re-run:
  - `npm run build`
  - `npm run package:preview`
  - `npm pack --dry-run --json`
  - runtime boundary/source boundary checks
  - secret/private scan
  - artifact high-risk scan
- Confirm git tree diff against staging branch only touches allowed files and docs.
