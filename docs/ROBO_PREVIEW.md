# Robo Preview

Robo Preview is a teaser-only surface. It exists to show that Sparkbot may later have hardware-adjacent preview concepts, but no control behavior is present in this public shell.

## Current Preview

- Static route and copy.
- No command controls.
- No device connection.
- No robotics, drone, humanoid, IoT, or browser/terminal execution.

## Boundary

Do not treat Robo Preview as a working hardware feature. Public release artifacts must not include private bridge code or live hardware adapters.

## Future Requirements

Any future hardware or device work needs a separate approval, safety model, permission gates, emergency stop design, audit evidence, and public/private boundary review.
