## Import Discipline

Layer 1 imported only the clean app frame, global navigation, static public shell, and public-safe docs links. Layer 2 added local-state chat/model config shell components only. Layer 3 added Workstation and Command Center shell refinements only. Layer 4 added Round Table local-state shell flow only. Layer 5 added memory/context contract previews only. Layer 6 added Task Guardian health-check report and app-first delivery contract previews only. Layer 7 added connector identity/PIN and fail-closed private recall contract previews only. Later layers can import or rewrite Task Guardian runtime, connectors, backend Round Table runtime, and real memory persistence only after each dependency is reviewed and validated.
