# Product Demo Polish Plan

Updated: 2026-05-24  
Branch: `frontend-only-product-demo-polish`

## Current Demo Storyline

1. Sparkbot Shell is a self-hosted AI workstation shell preview.
2. Workstation and Round Table are the primary demo surfaces.
3. Model seats and specialty agents show future operating structure.
4. Files, Memory, Tasks, and Demo Room fixtures show product context.
5. Guardian posture and Robo preview are visible with runtime boundaries.
6. LIMA AI OS remains a future contract/install layer.
7. Current gate is `GREEN_CANDIDATE` and `NOT_RELEASED`.

## Strongest Product Moments

- Round Table stage flow with recommendation artifact preview.
- Workstation floor organization across Chat, Round Table, setup, safety, and fixtures.
- Files/Memory/Tasks fixture shelves tied to one demo room.
- Clear LIMA future-gate panel without runtime claims.

## Unclear or Overdense Areas

- Top-level story required too much reading across sections.
- Some cards were copy-dense and mixed staging/runtime caveats.
- Round Table stage sequence was present but not highlighted as the core product narrative.
- Fixture sections were useful but did not clearly read as one connected storyline.

## Planned Polish Changes

- Tighten top-level headline/kicker copy and add a concise 3-step story strip.
- Add a Workstation storyline grid and simplify section wording.
- Emphasize Round Table hero sequence (framing, perspectives, synthesis, assignments, recommendation, artifact).
- Connect Files/Memory/Tasks fixtures directly to the same demo room context.
- Improve docs-page discoverability links for demo flow.
- Normalize wording across UI: `GREEN_CANDIDATE`, `NOT_RELEASED`, `static preview`, `demo fixture`, `Robo teaser only`, `future LIMA contract layer`.

## Public Safety Boundaries

- No backend, provider/model calls, connector calls, or network calls.
- No persistence, memory writes, scheduling, file upload/read/write behavior.
- No Guardian internals, terminal/browser execution, robotics/IoT control.
- No LIMA runtime wiring and no Arc/LIMA Office/LIMA IT integration.
- No Sparkbot R&D code import/copy in this pass.

## Intentionally Static / Mock Only

- All model-seat, Round Table, fixture, and guardrail data is local preview state.
- Recommendation artifact remains editable demo content only.
- LIMA integration remains docs/contract sequence only.
- Release state remains `GREEN_CANDIDATE`, `NOT_RELEASED`, `NO_TAG`, `NO_UPLOAD`, `NO_ANNOUNCEMENT`.
