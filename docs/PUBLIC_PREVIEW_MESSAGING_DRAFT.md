# Public Preview Messaging Draft

DRAFT / NOT ANNOUNCED

Sparkbot Shell is a clean public-preview self-hosted AI workstation shell that centers a round-table model for collaborative work between human operators and seat-based agents, with Workstation controls and memory/context previews designed for local-first evaluation.

## Included

- Workstation static UI for desk-style local work organization.
- Main Chat and Round Table collaboration previews.
- Invite Wing and specialty-agent surface previews.
- Local AI setup form previews and safety guardrail profiles.
- Task Guardian health-report and delivery preference preview shells.
- Connector setup and identity preview surfaces with clear out-of-scope notes.
- Robo teaser block with non-functional hardware-control boundaries.
- Artifact package and MIT framing for static preview.

## Intentionally Not Included

- Live model/provider calls.
- Live connector sessions or sends.
- Memory persistence and retrieval runtime.
- Scheduler/task execution runtime.
- Terminal/browser/file-system execution.
- Robotics/IoT control.
- LIMA/Arc/Office/IT live runtime.
- No final v1.0.0 claim without explicit Phil approval.

## Why it matters

This release gives builders a concrete shell interface to evaluate the product direction without shipping private runtime or proprietary internals. It is the first public artifact boundary before LIMA AI OS contract and runtime layers are introduced later through explicit, phased approvals.

## Robo/IoT Teaser Note

Robo is explicitly present as a teaser/demo placeholder. It demonstrates future direction only and does not execute any hardware or robot action in this release.
