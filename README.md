# Sparkbot Shell

Open-source self-hosted AI workstation shell for local-first agent work, model routing, and multi-agent Round Table meetings.

Sparkbot Shell is the clean public release track for Sparkbot. It is designed for hobbyists, builders, and open-source users who want a local/self-hosted AI command center without depending on a hosted SaaS agent platform.

Sparkbot Shell is the public, community-friendly Sparkbot direction: an exciting workstation for model-flexible agent work, visual meetings, files, basic memory, and safe local tools. It should stand beside tools like OpenClaw and Hermes as a self-hosted AI workstation for hobbyists, builders, and agent experimenters.

## Public Product Boundary

- Sparkbot Public = open-source shell / community buzz / hobbyist workstation
- LIMA AI OS = universal reasoning/runtime operating system for bots, automation, agents, robots, drones, humanoids, and IoT
- Arc Bot = proprietary guarded business worker-bot shell
- LIMA Office = proprietary business AI automation suite
- LIMA IT = proprietary IT/security/service layer
- Robo / IoT full control = paid/proprietary advanced LIMA system, not public Sparkbot core

## LIMA Relationship

Sparkbot Shell may eventually consume LIMA AI OS interfaces, but it is not the OS itself.

LIMA AI OS is the universal runtime and safety substrate for bots, automation, agents, robots, drones, humanoids, and IoT. Sparkbot Shell is a public application shell that can showcase the workstation, model, meeting, and safety ideas without exposing proprietary LIMA internals.

## Robo Tab Strategy

The Robo tab remains in the public shell as a teaser/demo surface. It should show future possibilities, simulated demos, docs, and upgrade path messaging.

Real natural-language robotics/IoT control belongs to advanced LIMA robotics/IoT systems and must not be included in the public core by default. Public Sparkbot Shell should not ship hardware control, live robot adapters, drone control, humanoid control, device dispatch, or hidden autonomy.
