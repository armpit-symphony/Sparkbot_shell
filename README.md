# Sparkbot Shell

Sparkbot Shell is the public-release staging repo for the open-source Sparkbot workstation: a self-hosted AI agent workspace with Workstation, Round Table meetings, model seats, and safe local-first controls.

This repo is for public-shell planning and sanitized extraction work. It must not receive proprietary LIMA AI OS, Arc Bot, LIMA Office, LIMA IT, robotics/IoT control, private deployment, client-specific automation, secrets, or internal R&D code.
